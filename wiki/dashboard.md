# 管理面板：顶栏与图表

管理面板地址 `/dashboard`（需登录，密码为 `config.json` 的 `dashboardPassword`）。单屏布局：顶栏 → 指标卡条 → 筛选区 → 图表区 → 工作区标签页。

## 顶栏

- **协议三段开关**（图表筛选区内）：全部 / Anthropic / OpenAI。切换后**下方所有卡片、图表、工作区整体切换**到该协议的方案集合
- **统计周期**（按日/周/月/年）：控制用户分布等图表的统计窗口
- **方案下拉**：只看某个方案的数据，或「全部方案」
- **自动刷新开关**：开启后面板定时拉新数据
- **设置 / 文档 / 退出**：「文档」在本窗口新开本手册

## 指标卡条

五张卡：**今日用量、今日请求、总用量、总请求、今日错误**。跟随协议与方案筛选。

口径要点（全部精确算式见[指标口径参考](metrics-reference.md#管理面板指标卡)）：

- 「今日用量」含缓存 token（input 列 2026-09-18 起各协议统一为新鲜输入，Codex 不再把缓存命中算进 input）；「今日请求」只统计**成功拿到回执的请求**（失败的不计入，只进错误记录）
- 「今日错误」受错误表「最近 200 条且 7 天」的双重保留约束，极高频时是下界
- 「在线」= 最后活跃距现在 1 小时内

## 六张图表

| 图表 | 数据来源与聚合 |
|---|---|
| Token 用量趋势 | 日汇总表，按周期分桶，桶内按用户分段 |
| 用户分布 | 日汇总/客户端日表，窗口整段累加；可切「按用户 / 按客户端」，跟随统计周期 |
| 模型请求分布 | 模型日表，按模型累加（不含缓存 token）；**可切「按模型 / 按方案」**（与用户分布的切换同款）：按方案维度显示方案名柱状图，不随用户筛选收窄 |
| 24 小时趋势 | 小时表，48 个半小时桶，双轴（请求数+总Token）；**仅统计单日**：选「按日」= 今天，或开始/结束日期设为同一天；跨多天窗口时不统计并在图头提示 |
| 24 小时模型趋势 | 同上单日口径，按模型分线（Top6 + 「其他」） |
| 方案请求情况 | 日汇总表，恒为全部方案（不随方案下拉收窄） |

- **统计周期窗口**：按日=今天；按周=本周一起；按月=本月 1 日起；按年=本年 1 月 1 日起（全按北京时间）
- 用户分布与模型请求分布两张图都有**维度切换**（图头右侧小开关）：用户分布切「按用户/按客户端」，模型分布切「按模型/按方案」；重置筛选后回到默认维度
- 半小时桶按北京时间取整；旧版整点历史数据自动对半拆分，不会错位
- 面板数据在自动刷新开启时**每 30 秒**拉取一次

图表下方是九个工作区标签页，逐个见[九个工作区](dashboard-workspaces.md)。

## 数据口径提醒

- 「今日」以**北京时间零点**为界
- 所有图表显示**真实 Token**（含缓存）；配额倍率只影响扣额，不影响这里展示的数字——两套口径的完整说明见[指标口径参考](metrics-reference.md#先搞清两套-token-口径)
