# 我的用量页

成员侧主页，地址 `/usage/<你的虚拟Key>`（也可在 `/my-usage` 输入 Key 跳转）。**无需登录后台**，持有 Key 即可查看自己的用量。左侧栏八个分区 + 右下角吉祥物挂件。

## 概览

- **协议切换**（全部 / Anthropic / OpenAI）+ **方案下拉**：切换查看范围
- **签到条**：每日签到领随机 token；显示今日奖励、连续天数、累计奖励。未签到时吉祥物会口头提醒
- **指标卡**：今日用量、今日请求、今日输入 / 输出、缓存写入、缓存命中
- **配额提示条**：临时加量、今日已重置、AUTO 自动调整、当前倍率等状态提示
- **各方案配额卡片区**：选「全部可用方案」时，每个可用方案一张卡——配额进度条（按紧张度着色）、配额来源、倍率与抵扣、（有调度时）下次切换时刻
- **使用日历**：GitHub 风格的年度热力图（往回 371 天，含今天）。**着色是相对自己的分位数**——活跃天的 25/50/75 分位切 5 档色阶，深色 = 超过你过去一年 75% 的活跃天；悬浮看当日明细，下方汇总活跃天数、最长连续、最高单日（「最长连续」统计的是有记录日期的连续段，无流量的日子不在序列里、不会打断计数）
- **产出画像**（仅自己可见）：净产出、失败率、缓存命中率建议、趋势

## 配额价目表

当前时段**每个别名**的倍率一览，**最便宜的排最前**；模型单独定价按真实上游模型名匹配，倍率锚定 ×1.0 = 高峰时段默认价。倍率怎么算的见[配额与计费机制](mechanism-quota.md#峰谷倍率怎么选)。花钱之前先看这页，选便宜又够用的模型。

## 用量分析

- **日期范围 + 快捷周期筛选**：默认选中「今日」与「本周」，点「重置」恢复默认档
- **今日 24 小时趋势图**：半小时粒度（48 桶，北京时间），跟随日期范围筛选
- **用量趋势**：双轴折线图
- **今日模型请求表**：请求数、实际 Token、倍率、计入配额四列**并排**展示——「实际 Token」= 输入+输出（不含缓存），「计入配额」= 计权后的扣减值，两列差额就是倍率与缓存剥离的折算效果（详见[配额与计费机制](mechanism-quota.md#weighted_tokens-配额货币的完整公式)）
- **客户端用量表**、**项目分布表**（文件数 / 净产出 / Token / 缓存率）

## 会话使用情况

自己的会话卡片：可读标题、客户端、Token、缓存率、净产出；支持日期范围与快捷周期筛选。

## 团队排行榜

按排序维度（可切换）+ 时间窗（今日 / 7 天 / 30 天）的团队排行，前三名有领奖台样式。

- **样本不足**：缓存率 / 上下文健康度要求本期请求 ≥ 50 次、效率比要求净增 ≥ 50 行、代码质量要求编辑 ≥ 10 次才参与排名。不达标者数值照常显示并带橙色「样本不足」标，但排在所有达标者之后，也不进领奖台——防止只发几次请求就靠高命中率登顶
- **无人达标**：本期没人过门槛时（今日窗口常见），榜单上方会注明「按原始数值排序，仅供参考」
- **代码类维度只统计代码**：写 `.md` 等文档不算代码行数、不参与代码质量评分（详见[指标口径](metrics-reference.md)的「团队排行榜」一节）
- 领奖台只在前三名全部达标时出现；cohort 行会显示「本期 N 人活跃 · 其中 K 人达标」

## 配置 Claude Code / 配置 Codex

两个配置分区，内容见[接入配置](setup-guide.md)：

- **配置 Claude Code**：一键脚本（macOS/Linux 与 Windows PowerShell 两个平台）、手动 `settings.json` 片段、**cc-switch 一键导入**深链；入口地址按你是否在某个方案组内自动计算
- **配置 Codex**：页内分区不跳转，一键脚本 / 手动 `config.toml` + `models.json` / **cc-switch 一键导入**；模型目录来自管理员的方案别名配置

## 配置 MCP

第三个接入指南分区：把 CC Team 的 MCP 端点接进你的 Claude Code / Codex，让 Claude 能查你的配额、看价目表、帮你签到、提交加量申请、翻使用手册。页面按你的虚拟 Key 与访问地址**现算**接入命令（Claude Code 一条命令、Codex 一段 `config.toml`），复制执行即可。工具清单与安全说明见 [MCP 接入](mcp.md)。

## 申请加量

页面上的「**申请加量**」按钮：选额度池、填理由提交；弹窗内可看自己历史申请的状态与管理员备注。审批在管理员侧（见[用户与配额管理](users.md)）。

## 吉祥物挂件

右下角的吉祥物：

- 10 种角色可选（熊 / 兔 / 猫 / 水獭 / 熊猫 / 小熊猫 / 羊 / 烤面包机等），视线跟随鼠标，点击有表情，浮层里换角色
- **进页问候**：按时段问候 + 一句话的今日用量简报；未签到时提醒签到，签到后道贺
