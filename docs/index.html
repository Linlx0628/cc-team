核心能力

把团队共享 API 变成可管理的资源

代理

透明转发

请求和响应保持原样，网关只处理虚拟 Key 映射、路由、配额与统计。

密钥

成员隔离

每个成员使用自己的 jx- 虚拟 Key，真实上游 Key 不暴露。

监控

用量可视化

按成员、模型、日期和小时查看 Token 消耗，管理员和个人页面分开呈现。

配额

每日限额

支持方案级和成员级配额，自动增长额度可覆盖高强度使用场景。

客户端

Claude Code 专用

围绕 Anthropic Messages 请求路径设计，别名、配额和统计行为保持一致。

稳定性

熔断与限流

连续上游失败自动熔断，配合并发和分钟级限流降低异常消耗。

部署

保留单文件项目的低维护成本

Docker

推荐 
docker pull linlx/cc-team:latest

docker run -d \
  -p 6789:6789 \
  -v cc-team-config:/app \
  --name cc-team \
  linlx/cc-team:latest

docker exec -it cc-team vi /app/config.json
docker restart cc-team

脚本启动

本地运行 
git clone https://github.com/Linlx0628/cc-team.git
cd cc-team

./start.sh

# Windows
start.bat

客户端接入

export ANTHROPIC_BASE_URL="http://localhost:6789"
export ANTHROPIC_API_KEY="jx-your-virtual-key"
