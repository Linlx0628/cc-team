### 段：后端 Java / JVM

> 本段适用于 `*.java`、`*.kt`、`*.kts`、`pom.xml`、以及 MyBatis 的 `*Mapper.xml` / `*Dao.xml`。
> 引擎自带的 Java 清单会自动合并生效（本段与它冲突时以「通用」的禁止清单为准）。

#### 空指针与集合

- 解引用前确认取值来源：方法返回值、`Map.get`、`Optional.get`、自动拆箱、`Long`/`Integer` 比较，都要沿数据来源调用链读过再判。
- 集合按下标取元素、`subList`/`Arrays.asList` 视图的越界与结构性修改。
- 数组/集合的长度与循环边界是否一致（**边界错误优先于风格问题**）。
- `Optional` 判断了存在性之后又调 `get()`，中间可能已被改变。

#### 事务与数据一致性（本段优先级最高）

- `@Transactional` **自调用失效**（同类内部方法调用绕过代理，注解不生效）。
- 事务方法里包了远程调用/发消息/慢 IO —— 事务被拉长，且失败时外部副作用无法回滚。
- `try/catch` 把异常吞掉或转成返回值，导致**该回滚的没回滚**。
- 事务传播行为用错（`REQUIRES_NEW` 打断外层事务、`NOT_SUPPORTED` 让写操作脱离事务）。
- 批量写入没有包在一个事务里：中途失败留下半成品数据。
- 金额用 `double`/`float` 参与运算或累加；单位（元/分）在跨方法传递时不一致。

#### 并发

- 先检查后使用（check-then-act）：判断和写入之间存在中间态。
- 非线程安全容器（`ArrayList`/`HashMap`/`SimpleDateFormat`）被多线程读写。
- 双重检查锁缺 `volatile`、单例或缓存的惰性初始化缺陷。
- `ThreadLocal` 用完不 `remove()`：线程池复用导致串数据。
- 只在**有证据证明会被并发调用**时报（用 `code_search` 查调用上下文）；方法内局部变量、只读操作、已用 `synchronized`/`Lock`/原子类保护的不报。

#### 性能（要有量级依据）

- 循环里查库或发远程请求（用 `code_search` 确认该方法真的访问 DB/网络）。
- N+1：先查列表再逐条 `getById`/`selectOne`，应指出可改批量查询。
- 查询没有分页/没有上限条件，可能全表拉取。
- 嵌套循环里的高阶复杂度（O(n²) 及以上）且数据量无上界。

#### MyBatis / Mapper XML

- `#{}` 被写成 `${}`：**SQL 注入**（`${}` 是字符串拼接，除非是表名/排序字段这类确实不能用占位符的场景，且必须确认取值不来自用户输入）。
- `foreach`/`<if>` 动态条件漏判，导致全表更新或全表删除（缺少 `WHERE`）。
- `resultMap` 字段与列名错配、`parameterType` 与实际入参不符，导致静默取到 null。
- 同名查询在多处被复用，改动 SQL 时未核其它调用点。

#### Maven（`pom.xml`）

- 必填项/语法错误会导致构建失败（重复的 `dependency`、缺 `groupId/artifactId/version`、标签未闭合）。
- 依赖 `scope` 写错：本该 `provided`（容器提供）的写成默认 `compile`，或反之，导致运行时 `ClassNotFoundException`。
- 同一个依赖声明了两个不同版本（版本冲突）。
- 引用了不可达的仓库地址。
- 只评「会导致构建失败或运行时异常」的，不评依赖升级建议、不评版本新旧。
