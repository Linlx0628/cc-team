CC Team

团队 AI 编码用量网关。一个 Node.js 进程同时服务 Claude Code 与 Codex，处理透明转发、Token 统计、峰谷配额倍率、产出质量分析和多上游方案接入。

核心能力

把团队共享 API 变成可管理的资源

代理

双协议接入

Claude Code 走 Anthropic Messages（/v1/messages），Codex 走 OpenAI Responses（/v1/responses）。两种协议的方案完全隔离，各自路由、各自 failover，互不接管。

密钥

成员隔离

每位成员使用独立的 jx- 虚拟 Key，真实上游 Key 不暴露。把一个链接发给成员，即可按页面指引一键完成 Codex 接入。

配额

峰谷倍率

方案级与成员级每日配额，北京时间零点重置。高峰/低谷按时段计权扣额，还可按模型单独定价，低谷与廉价模型自动更省额度。

稳定性

熔断与回切

连续上游失败自动熔断并切换备选方案；冷却结束后自动探测回切，冷却时间指数退避。粘性会话把同一会话粘在同一方案上，保住缓存亲和。

监控

用量可视化

按成员、方案、模型、日期和小时统计 Token 用量。全部方案视图下配额按方案展开成一列列卡片，一屏看清各方案额度占用；个人页附 GitHub 风格年度使用日历。

质量

产出质量工作区

从工具调用流量提取净产出、失败率、重写率与 token 效率，项目自动识别。仅统计结构化指标，不存储任何代码内容；一键导出自包含 HTML 周期报告。

成本

等值成本

Token 按可编辑的参考牌价折算 USD，按成员与方案统计，支持峰谷分时计价。空转与错误循环实时告警，直达已配置的通知渠道。

成员

签到与加量

每日签到随机奖励 token 进入当日临时加量；加量申请即时推送管理员，后台一键发放或驳回。图片识别桥接让纯文本模型也能"看"图。

通知

事件推送

限流、熔断、failover 切换等故障与恢复事件实时推送到飞书、钉钉、企业微信、Server酱、Bark。全部管理操作记入审计日志，虚拟 Key 一律脱敏。

部署

保留单文件项目的低维护成本

Docker

推荐 
docker pull linlx/cc-team:latest

mkdir -p cc-team-data/backups
curl -fsSL https://raw.githubusercontent.com/Linlx0628/cc-team/master/config.example.json \
  -o cc-team-data/config.json
touch cc-team-data/data.db

docker run -d \
  -p 6789:6789 \
  -v "$PWD/cc-team-data/config.json:/app/config.json" \
  -v "$PWD/cc-team-data/data.db:/app/data.db" \
  -v "$PWD/cc-team-data/backups:/app/backups" \
  --name cc-team \
  linlx/cc-team:latest

升级容器时保留 cc-team-data/ 目录即可，不要把卷挂到整个 /app。

脚本启动

本地运行 
git clone https://github.com/Linlx0628/cc-team.git
cd cc-team

./start.sh

# Windows
start.bat

打开 http://localhost:6789/settings 完成上游、模型和成员配置。

接入 Claude Code

默认方案使用无后缀地址；指定方案时在地址中加入方案后缀（如 /glm），所有方案同时在线。

export ANTHROPIC_BASE_URL="http://localhost:6789"
export ANTHROPIC_API_KEY="jx-your-virtual-key"

接入 Codex

成员打开 http://<服务器>:6789/setup/<虚拟Key>，按页面指引一键脚本或复制配置；模型目录由方案的别名自动生成。

curl -fsSL "http://<服务器>:6789/api/codex-setup/jx-your-virtual-key" | sh
