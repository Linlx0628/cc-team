### 段：兜底（SQL / 配置 / 脚本 / 其他）

> 本段是所有未被前面各段命中的文件的兜底。**这一类里引擎真正会送审的是**：`*.sql`、`*.yml` / `*.yaml`、`*.properties`、`*.json`、`*.xml`（非 MyBatis）、`*.toml`、`*.ini`、`*.env`、`*.sh`、`*.gradle`、`Dockerfile` / `Jenkinsfile` / `Makefile`、`*.html` / `*.css`。
> 这一类**只查「会造成运行事故的问题」**，不做任何风格与措辞评审。
> （`.md` / `.txt` / `.vm` / `.conf` / `.lock` / `*.dockerfile` 引擎不会送审，无需在此考虑。）
> ⚠️ 引擎还有一层**按密级的排除**：名为 `.env`、`.env.local` 这类前导点 env 文件，以及 `.npmrc`、`.netrc`、`id_rsa`、`id_ed25519`，一律不送审；`*.pem` / `*.key` / `*.p12` / `*.jks` 与 `.env.example` 则因为后缀不在送审范围内，同样到不了你眼前 —— 不要对它们提意见，也不要因为它们没被检查而报「缺少配置」。

#### 凭据与开关（最高优先级）

- 明文的口令、令牌、密钥、连接串（`.env`、`application.yml`、`settings.xml` 是重灾区）：应走环境变量或密管。
- 危险开关：`debug: true`、关闭鉴权/校验、`privileged: true`、资源限制为 0、`replicas: 0`、把服务暴露到 `0.0.0.0`。
- 把生产地址指向测试环境（或反之）：错误的域名/端口/库名/桶名。

#### 会导致启动或构建失败的

- 键名拼错、缩进层级错误（YAML 尤其）、必填项缺失。
- 类型不符（该是数字的写成字符串）、同一个键重复出现。
- 依赖声明缺失或版本区间不可满足（`Dockerfile` 里装不上的包、`Makefile` 里不存在的目标）。

#### SQL

- 把外部输入拼进 SQL（字符串拼接 / `${}`）：注入。
- `UPDATE` / `DELETE` 缺少 `WHERE`，或 `WHERE` 恒真：**全表写 / 全表删**。
- 批量写没有事务保护；`DROP` / `TRUNCATE` 没有前置保护。
- 大表无 `LIMIT` 的全量扫描、高频查询条件缺索引（要有依据，不凭感觉）。
- 迁移脚本不可重复执行（缺 `IF EXISTS` / `IF NOT EXISTS`），或与已有结构冲突。

#### Shell

- 变量未加引号导致分词或空值展开；`rm -rf $DIR` 里 `$DIR` 可能为空 → 删到根目录。
- 缺少 `set -euo pipefail`，中间步骤失败被忽略后继续执行破坏性操作。
- 管道里前段命令的失败被忽略（退出码只来自最后一个命令）。

#### HTML

- 用户可控内容未经转义直接输出（模板变量、`innerHTML`）：**XSS**。
- 表单/接口地址写错、`action` 指向错误环境。

#### 时间与单位

- 配置里的超时/重试/间隔为 0 或负数，导致无限等待或不做重试。
- 时区配置缺失或与业务口径不一致（如定时任务按 UTC 却按北京时间预期执行）。
