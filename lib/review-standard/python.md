### 段：Python

> 本段适用于 `*.py`、`*.pyi`、`*.ipynb`。引擎自带的 Python 清单会自动合并生效。

#### 语法级陷阱（真实缺陷，不是风格）

- **可变默认参数**（`def f(a=[])` / `a={}`）：默认值在函数定义时创建一次，被所有调用共享并累积。
- 可变对象在函数间共享后被就地修改，调用方看到意外变化。
- 浅拷贝被当成深拷贝（嵌套结构仍共享）。
- `is` 与 `==` 误用（尤其与 `int`/`str` 字面量比较，以及 `is None` 之外的小整数缓存现象）。
- 异常处理：`except: pass`、`except Exception` 后什么都不做、或把异常转成返回值让上层无从判断失败。
- 在 `finally` 里 `return`/`raise`，吞掉原始异常。

#### 数据与并发

- 循环里访问数据库（ORM N+1：先查列表再逐条 `get`），要有量级依据再用 `code_search` 确认。
- 需要事务的多步写操作没有包在 `transaction.atomic()`/显式事务里，中途失败留下半成品。
- 误以为有 GIL 就不会有竞态：读-改-写复合操作、`+=` 累加仍然会丢更新；需要锁或原子操作。
- 多进程/多线程下共享的模块级可变状态。
- 金额用 `float` 累加；`round()` 的银行家舍入被当成四舍五入。

#### 资源与时间

- 文件/连接/会话没有用 `with`（或没有显式关闭），异常路径下泄漏。
- `datetime.now()`（naive，无时区）与带时区的时间混用、比较，导致偏移 8 小时这类错误。
- 用 `datetime.now()` 做「当天」的业务判断，跨时区或跨零点时口径不一致。

#### Web 与接口

- FastAPI/Flask/Django 的入参没有校验就落库；把请求参数直接拼进 SQL 或用 `f-string` 拼 SQL（注入）。
- 越权：只按传入的 id 取数据，没有校验该 id 属于当前用户/租户。
