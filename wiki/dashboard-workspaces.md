# 管理面板：九个工作区

管理面板图表下方的九个标签页。协议三段开关对全部工作区生效。

## 1. 用户用量

团队成员表格，每行一位成员：

- 请求数、输入 / 输出 / 缓存写 / 缓存命中 / 合计 Token、今日用量、最后活跃时间
- **在线状态 LED**：绿灯表示近期有请求
- **配额列**：成员只用一个方案时显示单个配额进度；多方案时自动**展开为每方案一列**（百分比 + 进度条，悬停可看已用/上限/配额来源/倍率/临时加量）
- **「只看配额」**按钮：折叠 Token 统计列，只留配额信息（偏好存在浏览器本地）

## 2. 客户端用量

按识别到的调用方客户端（claude-cli / codex_cli_rs / zcode / unknown…）统计请求数与 Token，用来回答「团队都在用什么工具跑」。

## 3. 明细记录

按**日 / 周 / 月 / 年**分组的周期明细：

- 关键字搜索、时间范围筛选
- 按时间 / Token / 请求数排序，分页
- 点击某个周期可展开看该周期的成员明细
- 「重置」一键清空筛选条件

## 4. 方案中心

各方案一张行：入口 URL、上游地址、今日请求、今日用量、状态徽章（**限流中 / 熔断中 / 默认组头**等）。按协议分节展示。排查「某个方案现在能不能用」先看这里。

## 5. 配额倍率

一张总表，列出**每个方案 × 模型**的当前倍率：

- 峰 / 谷两档倍率、今日实际 Token 与计入配额的加权值、请求数
- 设了**单独定价**的模型行有底色徽章（按**真实上游模型名**匹配，非别名）
- 表头汇总：当前时段（峰/谷）、单独定价模型数、今日综合倍率
- 实收与当前倍率不符时标注「实收 ×N」——中途改过倍率就会出现（历史按写入时的倍率冻结、永不追溯），属正常现象

## 6. 错误记录

最近的代理错误（429 / 403 / 503 等），可一键清除。**配额超限、并发超限、限流产生的 429 都会进这里**——成员喊「用不了」先来这里对时间点。429 的具体含义见 [FAQ](faq.md)。

> 注意：错误表只保留**最近 200 条且 7 天**，清空前的历史无法追查。

## 7. 产出质量

团队的产出分析工作台：

- **指标**：净产出、文件数、失败率、重写率、验证密度、Token 效率等——**每个指标的精确公式与着色阈值**见[指标口径参考](metrics-reference.md#产出质量指标公式)
- **时间筛选**：今日 / 近 7 天 / 近 30 天
- **导出报告**：生成自包含 HTML 报告，可直接发群里
- **指标口径说明**：弹层解释每个指标怎么算
- **告警列表**：系统自动扫出的异常（空转消耗 / 错误循环 / 编辑失败爆发，阈值见[指标口径参考](metrics-reference.md#产出告警的精确阈值)），可全部标记已读
- **项目分布**：按项目统计产出；会话跨多项目时整段记给主导项目

隐私边界：只记行数、文件路径、命令分类，**不存代码内容**；文件路径记录可在设置里关闭。

## 8. 会话使用情况

团队维度的会话面板：

- 每个会话一行：可读标题、客户端、Token、缓存率、净产出
- 支持**下钻**（点进单个会话看细节，可清除下钻）
- 今日 / 7 天 / 30 天筛选
- 会话标题的来源与缓存率的协议修正算法见[指标口径参考](metrics-reference.md#会话统计)

## 9. 等值成本

把 Token 按参考牌价折算成 USD（牌价在设置页维护，支持峰谷分时价）：

- 按成员、按方案两个维度统计
- 今日 / 7 天 / 30 天筛选
- **改牌价后全部历史立即按新价重算**（查询时现算）——它是参考工具，不是账单存档
- 计价公式、默认牌价表与峰谷规则见[指标口径参考](metrics-reference.md#等值成本计算)
