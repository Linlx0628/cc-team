# 管理面板：左栏菜单与数据总览

管理面板地址 `/dashboard`（需登录，密码为 `config.json` 的 `dashboardPassword`）。布局：**左侧菜单 + 右侧内容**（680px 以下侧栏折成顶部横条）。

## 左侧菜单

自上而下 11 项，点击切换右侧内容。**每个菜单只在自己被打开时才去查自己的数据**（后端按菜单返回，点「错误记录」不会顺带跑模型/客户端那几张宽表的全表统计），已经加载过的菜单在会话内不重复拉取。

菜单项不带数字角标；切换用鼠标点击或**键盘上下键**都行（两条路径都会触发加载）。

| 菜单 | 内容 |
|---|---|
| **数据总览**（默认） | 指标卡 + 六张图表 + 图表筛选 |
| 用户用量 | 各成员用量表 + 配额列 |
| 客户端用量 | 客户端 × 用户分布 |
| 明细记录 | 分组明细账（点周期可下钻到小时） |
| 方案中心 | 各方案今日概览 |
| 配额倍率 | 模型/方案倍率看板 |
| 错误记录 | 错误列表 |
| 产出质量 | 成员产出画像 + 项目分布 + 告警 |
| 会话使用情况 | 会话表 + 流水 |
| 等值成本 | 按参考牌价折算的成本 |
| 代码评审 | 评审触发与结果（有未读时会带角标） |

菜单底部：**设置**(跳转 `/settings`)、**文档**(新窗口打开本手册)、**退出**(登出并刷新)。

## 内容区顶部工具栏

- **方案下拉**：只看某个方案的数据，或「全部方案」（切换会作废各菜单已缓存的数据，并按当前菜单重新拉取）
- **自动刷新**：开启后每 30 秒刷新**你当前所在的那个菜单**（不会在后台把所有菜单的数据都重拉一遍）

## 数据总览

**指标卡**（五张）：今日用量、今日请求、总用量、总请求、今日错误。跟随协议与方案筛选。口径要点（全部精确算式见[指标口径参考](metrics-reference.md#管理面板指标卡)）：

- 「今日用量」含缓存 token；「今日请求」只统计**成功拿到回执的请求**（失败的不计入，只进错误记录）
- 「今日错误」受错误表「最近 200 条且 7 天」的双重保留约束，极高频时是下界
- 「在线」= 最后活跃距现在 1 小时内

**图表筛选**（只作用于图表）：协议三段开关（全部/Anthropic/OpenAI）、统计周期（按日/周/月/年）、指标、模型、用户、日期范围、重置。

**六张图表**：

| 图表 | 数据来源与聚合 |
|---|---|
| Token 用量趋势 | 日汇总表，按周期分桶，桶内按用户分段 |
| 用户分布 | 日汇总/客户端日表，窗口整段累加；可切「按用户 / 按客户端」 |
| 模型请求分布 | 模型日表，按模型累加（不含缓存 token）；可切「按模型 / 按方案」——「按方案」维度需要跨方案的日聚合表，**切过去时才单独查一次**（这是全页面最重的一项统计，所以不随数据总览一起拉） |
| 24 小时趋势 | 小时表，48 个半小时桶，双轴；**仅统计单日**（选「按日」或开始/结束同一天） |
| 24 小时模型使用趋势 | 同上单日口径，按模型分线 |
| 方案请求情况 | 日汇总表，恒为全部方案（不随方案下拉收窄） |

- 统计周期窗口：按日=今天；按周=本周一；按月=本月 1 日；按年=1 月 1 日（全按北京时间）
- 半小时桶按北京时间取整；旧版整点历史数据自动对半拆分，不会错位

## 数据口径提醒

- 「今日」以**北京时间零点**为界
- 所有图表显示**真实 Token**（含缓存）；配额倍率只影响扣额，不影响这里展示的数字——两套口径的完整说明见[指标口径参考](metrics-reference.md#先搞清两套-token-口径)
