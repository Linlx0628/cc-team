### 段：前端

> 本段适用于 `*.ts`、`*.tsx`、`*.js`、`*.jsx`、`*.mjs`、`*.cjs`、`*.vue`。
> ⚠️ 引擎自带的清单**没有覆盖 `.vue`**，`.vue` 只靠本段 + 通用段——改动 Vue 文件时按本段逐条核。

#### 资源与生命周期（最高频的真实缺陷）

- 事件监听（`addEventListener`）、定时器（`setInterval`/`setTimeout`）、WebSocket/`EventSource`、第三方订阅：注册了但组件卸载时**没有解绑**，导致泄漏与重复触发。
- Vue：`onUnmounted`/`onBeforeUnmount` 里漏了配对的清理；`watch` 没有在卸载时停止（`watchEffect` 的 `stop`）。
- React：`useEffect` 缺清理函数；依赖数组写错（漏依赖导致读到旧值 / 空数组导致只跑一次 / 每次渲染都新建对象导致死循环）。

#### Vue 响应式（团队高频踩坑）

- 直接改数组下标（`arr[i] = x`）或 `delete obj.k`：**不触发更新**（Vue 3 用 `arr.splice`/重赋值，Vue 2 用 `$set`/`$delete`）。
- 给响应式对象新增属性后没触发更新（同上）。
- 把 `props`/`reactive` 对象**解构**后使用：丢失响应性。
- `v-for` 缺 `key`，或用数组下标作 `key` 导致列表复用错位（删除/排序后状态串行）。
- `v-if` 与 `v-for` 同元素混用，作用域与优先级不符原意。

#### 异步与竞态

- 后发先至：连续请求/搜索，**先发的慢响应覆盖了后发的状态**（要有取消或序号校验）。
- 组件卸载后才落地的 `setState` / 赋值，导致报错或写脏状态。
- `Promise` 没有 `catch`（未处理的拒绝被静默吞掉）；`try/catch` 里 `catch` 到异常后什么也不做。
- `async` 函数在需要串行的地方被并发调用（如循环里 `forEach` + `await` 实际是并发的）。

#### 安全

- `v-html` / `innerHTML` / `dangerouslySetInnerHTML` / `eval` / `new Function` 接收了用户可影响的输入：**XSS**。
- 把后端返回的 URL/参数直接拼进跳转或请求。
- 把令牌、密钥、内部地址硬编码进前端代码（前端产物对所有人可见）。
- 前端做的权限/金额校验被当成安全边界（**前端校验不是安全**：真正的判定必须在服务端）。

#### 金额与数值

- 金额用浮点直接运算或累加（`0.1 + 0.2`）；元/分换算不一致。
- `toFixed` / `parseFloat` 用在金额上导致四舍五入错账。
- 大整数（如订单号、雪花 ID）用 `Number` 承载，超过 2^53 后精度丢失。

#### 类型与空值（TS）

- 用 `!`（非空断言）或 `as any` 压掉类型错误，而该值实际可能为空 —— 这是「把编译期错误推迟到运行期」，必须报。
- 可选链/默认值缺失导致渲染期读取 `undefined` 的属性（白屏）。
