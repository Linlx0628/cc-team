# 快速上手

## 管理员：部署后的第一步

1. **部署服务**：见[部署与运维](deploy.md)，三选一——`start.sh` 脚本、Docker、直接 `node server.mjs`。默认端口 **6789**。
2. **设置访问密码**：`config.json` 的 `dashboardPassword` 字段，这是管理面板的登录密码。
3. **建第一个方案**：打开 `/settings`，选协议（Anthropic 或 OpenAI），「＋ 新建」，填上游地址、模型别名、配额。详见[设置页](settings.md)。
4. **把方案排进方案组**：在侧栏「默认方案组 / OpenAI 方案组」编辑器里把方案按 failover 优先级排序，第一位是组头。
5. **建用户、发 Key**：设置页底部「用户管理」，创建成员的虚拟 Key，并给成员在方案上分配真实 Key 与个人配额。详见[用户与配额管理](users.md)。
6. **把接入方式发给成员**：让成员看[接入配置](setup-guide.md)，或直接把 `/setup/<虚拟Key>` / `/usage/<虚拟Key>` 链接发给对应成员。

可选进阶：

- 配置**高峰时段与峰谷倍率**（[核心概念](concepts.md#配额倍率-峰谷倍率)）
- 配置**方案组调度**，让不同时段自动用不同方案（[方案组调度](schedule.md)）
- 配置**通知渠道**（飞书/钉钉/企微/Server酱/Bark），接收产出告警（[设置页·通知设置](settings.md)）

## 成员：三步接入

1. **拿到虚拟 Key**：管理员发给你，形如 `jx-xxxx`。
2. **配置客户端**：三选一，见[接入配置](setup-guide.md)：
   - 一键脚本（在「我的用量」页复制，或管理员发的 `/setup/<Key>` 页面）
   - 手动改 `settings.json`（Claude Code）或 `config.toml`（Codex）
   - cc-switch 一键导入
3. **开始使用**：正常使用 Claude Code / Codex，用量会自动统计。打开 `/usage/<你的虚拟Key>` 看自己的用量、配额、签到领额度。

## 遇到 429？

先看 [FAQ：429 的几种含义](faq.md)——可能是你的个人配额用完（次日零点重置）、方案限流，或上游套餐限额（有恢复时刻）。
